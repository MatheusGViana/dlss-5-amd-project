# OptiScaler AMD PreSR Multipass v2.20

Lighting is enabled by default at 0.5. The menu now has one control, Lightning Strength; set it to zero to disable lighting. The strength controls activation, including when an older configuration contains AmdNeuralLighting=false.

Diagnostic collection scripts are no longer included or installed. Runtime logging remains available. Existing collection scripts in older installations are not removed.

Retains v2.19 shared frame stabilization and existing scale/highlight protections. Skin/character and appearance controls are unchanged; this release does not add a new skin reconstruction model or establish visual equivalence with NVIDIA.

Release compilation verified. Visual quality, frame-generation interaction and GTA timeout recovery still require in-game testing.

Extract the complete package and run INSTALAR_AMD.bat with the game closed. Attribution and license notices retained.
