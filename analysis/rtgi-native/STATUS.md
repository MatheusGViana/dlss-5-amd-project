# Native Diffuse - 2026-09-08

Integrated in RtgiNative.cpp and AmdPreSr.cpp; controls persist under [AmdRtgi]. Disabled by default. The pipeline uses distinct descriptor tables per dispatch, explicit barriers, and the owning AMD completion fence before reuse/resize. Native assets are generated by BUILD_RTGI.ps1 and copied by Setup.

Implemented: input color/depth/motion preparation, five depth mips, reconstructed geometry normals, five radiance stages, trace with original noise/permutation assets, moments, reprojection, history, denoising, albedo pyramid/fusion and composition.

Validation: radiance constant-scene tests; trace sky/plane/concavity tests; temporal reset/valid/out-of-screen/depth rejection; whole pipeline odd/even extents and 512-wide scenes; neutral composition preserves input. AMD integrated test includes forced neural timeout, recovery, motion/exposure conversion and queue changes.

Limits: experimental, no in-game validation yet. Manual FOV/depth range, reconstructed normals, pre-exposed color adaptation. Typed depth-stencil conversion not implemented. GPU/VRAM costs not benchmarked. The separate HIP capture stall remains unresolved. RTGI requires enabled AMD neural/pre-SR in this integration.
